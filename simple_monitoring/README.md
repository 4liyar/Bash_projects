This is a simple monitoring project using netdata from roadmap.sh website.

The goal was to:

* install netdata 
* access it's dashboard
* customize the dashboard and set an alert
* writing a script to automate installation steps of the netdata
* writing a script to automate testing of the dashboard by putting some load on the system resources
* writing a script to automate removing netdata and cleaning-up the system.
